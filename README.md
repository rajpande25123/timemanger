# Little Steps Planner

A pastel lavender personal planner built with plain HTML, CSS and JavaScript.

## Features
- Home dashboard with live date, daily tasks and progress.
- Clickable monthly calendar with task indicators and selected-day task details.
- To-do list with categories, completion state and unfinished tasks carried forward to today.
- Daily timetable checklist (college 10 AM–5 PM, gym 5–7 PM, coding, English communication, Japanese N5, revision, meals and sleep).
- Weekly gym routine with strength sessions, recovery guidance and Sunday as a full rest day.
- Tiffin tracker at ₹50 per tiffin with monthly totals.
- Responsive layout for phones, tablets (portrait/landscape) and desktop; touch-friendly navigation.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or open this folder in VS Code.
3. Optional local server: run `python -m http.server 8000` in this folder, then open `http://localhost:8000`.

## On Moto Pad 60 Pro
Copy/extract the folder on the tablet or host it on your local network, then open `index.html`/the local server URL in Chrome. For a desktop-like full-screen experience, use Chrome's **Add to Home screen** option if available. The interface adapts to portrait and landscape widths.

## Data storage
Tasks, routine checkmarks, English practice status and tiffin records are stored in browser local storage on that device and browser. They do not automatically sync to other devices and can be lost if browser site data is cleared. Export/cloud backup is not implemented.

## Notes
The gym plan is general beginner guidance, not a personalized medical or coaching plan. Learn technique with a qualified trainer, choose manageable loads, and stop for sharp pain or dizziness. Sunday is a full rest day; Wednesday and Saturday are intentionally lighter.
